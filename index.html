Dados & Importação

Configure os ativos manualmente, importe cotações históricas do Yahoo Finance ou envie uma planilha Excel/CSV.

⚠ Aviso educacional: Esta ferramenta tem fins exclusivamente acadêmicos. Os resultados são baseados em dados históricos e estimativas fornecidas pelo usuário. Retornos passados não garantem resultados futuros. Não constitui recomendação de investimento.

Matriz de correlação

Importar via Yahoo Finance

Digite os tickers separados por vírgula.
🇧🇷 Ações B3: adicione .SA (ex: PETR4.SA, VALE3.SA)
🇺🇸 EUA: sem sufixo (ex: AAPL, MSFT, TSLA)
Os retornos e volatilidades são calculados automaticamente a partir de preços mensais históricos.

ℹ Os dados são obtidos via proxy público (allorigins.win → Yahoo Finance). Disponibilidade pode variar. Para uso em produção, recomenda-se API própria.

Formato esperado da planilha:

Coluna B: Retorno esperado em % ao ano (ex: 18.5)
Coluna C: Volatilidade em % ao ano (ex: 32.0)
Colunas D+: Correlações entre ativos (opcional)

⚖ MODERADO
